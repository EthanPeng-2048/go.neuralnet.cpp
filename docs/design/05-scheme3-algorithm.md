## 0. 核心主张（一句话）

Encoder 提供直觉基线 z₀；Decoder 在 Top-K 候选的受限搜索空间内生成**受语法约束的
控制 token**，经**显式搜索状态累加器 + 连续残差头**真正改变落子分布；停止决策由
边际收益驱动；最终以"固定小延迟下逼近高 visits 教师分布"达成搜索摊销。

## 1. 问题形式化

- 输入：局面 s =（盘面、历史、全局规则特征），特征定义引用
  [02 方案 1](02-scheme1-encoder-transformer.md) §4。
- 教师 T：高预算搜索策略 π^H 与其搜索树 𝒯 = {节点: (P, N, W, Q, parent, a)}。
- 学生推理形态：**一次直觉前向 + ≤ L 步自回归**，总延迟与直觉网络同量级。
- 目标：学映射 F_θ: s ↦ (π_final, v, stop)，使 π_final 在小延迟下逼近 π^H，
  且逼近过程是**受结构约束、可重放**的搜索修正，而非自由文本生成。

**核心分解**（本方案与"思考链文本生成"的根本区别）：

```
z_final = z₀ + Σ_{t=1..T_stop} Δz_t        （连续残差，非 argmax 累积）
```

token 序列决定 **Δz 语义上指向哪里**（看哪个候选、扩展哪条线），残差头决定
**改多少**（连续向量）；数值回溯（W/N 累加）在网外的确定性模块完成。

## 2. 表示与 Encoder

- 输入平面集：棋子、气、劫、征子相关、全局贴目/手数/规则；显式编码
  **上一手位置、连续 pass 数、ko 禁入点**——这三类信息无法从可学习位置编码
  可靠恢复【已确立：信息论上可区分，工程上须显式】。
- Encoder 主干：Residual 与 Transformer 交错；二维可学习频率 RoPE。
  交错结构为**工程假设**，须以自有消融证明，外部数字（【待核实】）不作预期。
- 输出：z₀ ∈ R^362（合法掩码后），v₀ + 不确定度 u₀，以及 Encoder 表征 H
  （供 Decoder cross-attention）。
- 规模参数（算法级）：Encoder 主干、Decoder、残差头的相对比例见 §10 消融扫描。

## 3. Top-K 槽位语法（形式语言）

**只搜索直觉 Top-K 候选及其受限衍生**（K 起步 5），不搜索全盘。分支因子爆炸
由构造消除。

- 槽位：c₁…c_K，按 z₀ 排序，**索引固定贯穿整条序列**；
- 派生点 d_j：当前分支的一个后续点（应手/连接点），由候选选择器给出；
- 深度 p ≤ P_max（起步 2）。

**事件表**：

| 事件 | 参数 | 对状态的强制作用 |
|---|---|---|
| `<expand>` | slot, depth | 新建节点 (N=0, P=prior[slot]) |
| `<eval>` | slot, depth, Δv 来源=残差头 | 叶子评估：W += Δv, N += 1，沿路径累加祖先 |
| `<backtrack>` | slot | 无访问；仅改变后续采样掩码 |
| `<deeper>` | slot | 允许 depth+1 展开（一次性配额） |
| `<stop>` / `<converge>` | — | 终止；输出当前 π_root |

**合法转移函数** 𝒜(state) → 允许事件集（自动机定义）：

- `<eval>(c,d)` ∈ 𝒜 ⇔ `<expand>(c,d)` 已发生；
- `<deeper>(c)` ∈ 𝒜 ⇔ `<expand>(c,1)` 已发生且该槽位 P_max 配额未用；
- 每 (slot, depth) 的 `<eval>` 配额 ≤ R（防止单分支垄断预算）；
- 序列以 `<stop>`/`<converge>` 唯一结尾。
- **违反 ⇒ 该 token 的 logit 置 −∞**（解码时硬掩码）；训练计入结构非法率。

**长度上界推导**：L ≤ K·(1 + R + 1 + R) + 2。K=5, R=3 ⇒ L ≤ 42 ≤ 48 ✓。
L 由构造可控（修复 v0.1 的序列爆炸问题）。

## 4. 显式搜索状态 + 可微 PUCT（核心模块）

自回归网络无法可靠学会 W/N 精确累加【已确立：浮点累加非 Transformer 的可靠
归纳偏置】→ 该部分**移出网络，做成确定性、可重放模块**：

1. 节点表 (P, N, W, Q=W/N)；P = softmax(z₀) 在槽位上的归一化。
2. `<eval>` 事件：残差头输出该叶子的价值分量 Δv ∈ R，更新路径祖先
   (W += Δv, N += 1)。
3. 根优先级重算（标准 PUCT）：

   `PUCT(a) = Q(a) + c_puct · P(a) · √(Σ_b N(b)) / (1 + N(a))`

4. 根分布 π_root = N / ΣN（**训练时固定此约定并与教师对齐**）。

**梯度路径**：L_policy 经 softmax(z₀ + ΣΔz) 回传到残差头与 Encoder；累加器本身
无参数（c_puct 除外，可固定或可学习）。模块是**事件驱动的差分执行器**——每个
token 必须产生可验证的状态转移，从构造上排除"幻觉搜索"。

【迁移假设】K=5、depth≤2 的截断搜索能否还原高 visits 修正的主体——H1 的直接
检验对象（§9）。

## 5. 残差监督 Δz* 的构造

残差头**不自由发挥**，监督目标由教师树差分生成：

1. 双预算树对：同一局面 s，教师以预算 N 与 N+Δ 各跑一次，得 π^L、π^H。
2. **规范化 log-ratio 目标**（消除 logits 的规范自由度）：

   `Δz* = log(π^H + ε) − log(π^L + ε)`   （仅合法集上，ε 为平滑常数）

3. **逐事件对齐**：把教师树映射为合法 token 轨迹（映射算法：按 PUCT 优先级
   序遍历教师节点，展开为 `<expand>/<eval>` 事件，切换分支时插入 `<backtrack>`；
   每个事件步的 Δz*_t = 该事件加入前后教师根分布的 log-ratio 增量）。
4. 双目标：‖Δz_t − Δz*_t‖²（回归）+ KL(π_root^student ‖ π_root^teacher)（分布）。

由此，模型学的是**可验证的数值修正方向**（教师搜索的边际贡献），不是 token
字符串的表面模式。

## 6. 损失

| 损失 | 形式 |
|---|---|
| L_policy | KL( π^H ‖ softmax(z₀ + ΣΔz) ∘ 合法掩码 ) |
| L_resid | Σ_t ‖Δz_t − Δz*_t‖² + λ₁·KL(π_root^t ‖ π_teacher^t)，按事件步对齐 |
| L_value | MSE(v_pred, v_teacher)，高不确定度样本加权 |
| L_token | 结构 token 交叉熵，**带合法转移掩码** |
| L_legal | 非法序列硬惩罚 / 重放失败率（可为非可微指标） |
| L_stop | 成本敏感：早停误判权重 ≫ 晚停浪费权重，以剩余时间为条件 |
| L_margin | ĝ_t（边际收益预测）与反事实实测 Δ质量 的 MSE |

`L = L_policy + α·L_resid + β·L_value + γ·L_token + δ·L_stop + ε·L_margin`
起始权重 α=1.0, γ=0.3, δ=0.2, β=ε=0.1；**唯一调参依据 = 残差探针**（§9 H1）。

## 7. 停止准则（数学形式）

- **预分配**：L₀ = f(H(z₀), u₀, phase)（熵 + 不确定度 + 局面阶段 → token 预算档位）。
- **逐步停止**：停止头输入 h_t =（当前隐状态, ĝ_t 预测边际收益, 剩余时间比例,
  JS(π_root^t ‖ π_root^{t−1})）；继续条件为收益-时间比：

  `继续 ⟺ ĝ_t / ĉ > λ₀ · (剩余时间 / 总预算)`

  其中 ĉ = 单 token 延迟估计。剩余时间少 ⇒ 门槛自动升高 ⇒ 倾向停止。
- **硬守卫与 anytime**：预留 15% 时间做最终前向与 IO；触线即输出当前
  π_root，不做半截序列。

| 阶段 | 内容 | 进入条件 | 退出（算法判据） |
|---|---|---|---|

## 9. 假设与证伪判据

- **H1（信息可蒸馏）**：存在 ≤L 的受结构约束修正序列使末端 logits 显著逼近 π^H。
  判据：残差探针（喂真实序列、不自回归）相对 π_low 的 top-1 提升 ≥8pp、
  JS 下降 ≥15%【验收参数，实测口径归 06】。失败 ⇒ 方向转向更强 Encoder /
  更大教师数据，不加 Decoder。
- **H2（结构优于自由文本）**：同参数、同 L 下，结构约束 + 状态累加同时优于
  自由 token 生成与等参数纯 BC。
- **H3（预算分配净收益）**：自适应触发 + 时间条件停止在同延迟预算下优于
  固定长度与全量触发。

**前置竞争解释排除**（针对蒸馏一致率单调下降，v0.2 §1.1 继承）：标签侧
（根噪声/温度/掩码/规则不对齐）、目标侧（hard vs soft、未归一化）、训练侧
（LR×epoch 灾难遗忘）、度量侧（教师自身 N vs N+Δ 稳定性上界）——四项诊断
全部先行，**教师自身稳定率若只有 0.5，学生一致率不能解读为蒸馏失败**。

## 10. 消融设计

1. **结构必要性**：打乱 token 顺序 / 等长随机合法序列——性能不降 ⇒ 模型未用
   结构（H2 失败，停线）；
2. **对照**：等参数纯 BC（只学 π^H）、自由 token 生成（无语法/无累加器）、
   关闭累加器（token-only）、关闭残差头（纯 π_root）；
3. **容量扫描**：K ∈ {3,5,8}、P_max ∈ {1,2,3}、R、L 上限；
4. **专项分桶**：征子/对杀/劫争/循环棋形/大模样——与 Encoder 增益解耦测量。

## 11. 与方案 1 / 2 的关系

- **复用方案 1（02）**：特征平面、Encoder 主干、双头、合法性掩码、GoLoss 打包
  全部继承；方案 3 = 方案 1 + Decoder 控制层。
- **取代方案 2（03）的地位**：方案 2 的纯 token 思考链的两个缺陷被本方案修复
  ——①幻觉搜索 → 显式累加器强制状态转移；②分支因子/长度不可控 → Top-K 槽位
  语法。**方案 2 保留为教师不可得时的回退**（自蒸馏教师 = 自研 MCTS，见 06）。
- **与 D9 兼容**：全程监督蒸馏，无自对局、无策略梯度；上游 v1.12.0 已提供
  RL 原语，但本方案不依赖自对局训练。

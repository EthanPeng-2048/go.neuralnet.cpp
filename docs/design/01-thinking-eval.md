# 01 — Thinking 路线评估：B + 推理时思考 vs MCTS

> 状态：**评估稿**（2026-10-23）· 对应决策 D8（🔶 待拍板）· 结论供拍板，**未进入主线**
> 原始问题：借鉴 o1/R1 式 Thinking 模型，让模型直接拥有思考能力——不靠 MCTS
> visits 也能自动推演后续局面？训练成本会不会更低？Go 能否像 LLM 那样自进化
> RL 出思考链？

## 0. 结论（TL;DR）

1. **不进主线**。thinking 不是 visits 的替代品，而是**把树摊成线的另一种记账**：
   o1 式长思考烧的是同一份推演算力（inference-time scaling = 多花算力，不是省算力）。
2. **单节点经济账上思考链其实占优**（KV cache：每 ply 30 MFLOP vs MCTS 叶子整段
   重跑 2–3 GFLOP，~100× FLOP / ~5× 墙钟）——本文初版按"30× 更贵"下过结论，
   查证 `GPTModel::generate` 的 KV cache 后**修正**。但串行无法跨局批量，自对局
   端到端仍 ~10× 慢；更关键的是**节点质量差一档**（见 §2）。
3. **决定性否决在训练侧**：R1 能成的三样前置我们一样没有，且训练成本至少 10×、
   链无处可 SFT（§3、§4）。
4. **关键路径论证**：即使 thinking 最终更强，其冷启动数据唯一来源 = MCTS 蒸馏
   ⇒ 它依赖 M8、排在关键路径最后，赌约时间线内塞不下（§5）。
5. **保留 M10 出口**：MCTS → 结构化思考链蒸馏 + 规则引擎**逐步验证**奖励——
   Go 独有、LLM 拿不到的中间步骤可验证性，比"直出坐标"更有创新性（§6）。
6. 澄清：**B 方案从未被放弃**——本评估的对象是"B + 推理时思考"这个变体。

## 1. 概念澄清：thinking = visits 的串行记账

- o1/R1 的推理时扩展 = **用生成 token 买算力**（inference-time compute scaling），
  长思考 = 更多算力，不是更少。"没有 visits"实际是"把 visits 换成 token"。
- 真正的问题：**同一份算力，树记账和线记账，哪种换来的棋力多？** §2、§3 分账。

## 2. 推理经济账（修正版）

口径：B-final（d=256/12 层，~15M 参数），40HX（448 GB/s），f32 权重 60MB。

| 节点类型 | 每节点成本 | 依据 |
|---|---|---|
| 思考链 decode 1 token | **30 MFLOP** + 重读权重 ≈ 0.15–0.3ms | KV cache 保住历史，每步只算新 token 的 Q×K_history；60MB/448GB/s = 0.134ms 带宽下限 |
| MCTS 评估 1 叶子 | **2–3 GFLOP**（整段 ~100 token 上下文重跑）≈ 0.75–1.5ms（批量摊薄后） | 树内无 KV 复用（每个叶子是不同盘面，上下文不可共享） |

**单节点：思考链 ~100× FLOP / ~5× 墙钟占优**（线性生成天然享受 KV cache）。
但它输在三处：

- **串行**：无法跨 64 局批量（MCTS 每批只读一次权重）。端到端自对局：思考
  1000 token/手 × 200 手 ≈ 50s/局 vs 40 visits ≈ 5s/局 ⇒ **~10× 慢**——
  但注意这个 10× 主要来自它每手探索 25× 更多节点（1000 vs 40），非单节点效率。
- **节点质量**：MCTS 节点 = 规则引擎精确盘面 + 价值回传（叶子评估摊成内部节点
  minimax 值）+ PUCT best-first。思考链节点 = 隐状态推导盘面（**无外部校验**，
  深度超过 5–10 手后错误率只能实验测定）+ 无回传（只能靠文本里记着上一条线的
  结论这种弱聚合）+ 分支一经写出处不回。
- **盘面推导方式**：思考模式下没有新盘面输入（conv 分支只编码真实盘面），模型
  必须从"真实盘面 + 想象走子 token 序列"经注意力重新推导当前想象局面——**可学，
  但组合深度受网络深度限制**（12 层网络对 30 手组合的表达能力未知），且错了没有
  任何机制发现。

**先例**：上游已有完整 KV cache 增量解码（`GPTModel::generate` +
`GPTBlock::forward_step`，逐 token、滑动窗口重建）——B 复合层要做思考式
decode 需自写 `forward_step`（有先例可抄，仍是排期外工程量）。

## 3. 训练经济账（口径可审计）

口径：fwd/token = 2×15M ≈ 30 MFLOP；fwd+bwd ≈ 90 MFLOP；每局 200 手。

| | MCTS 管线 | thinking（1000 token/手） |
|---|---|---|
| 自对局生成 | 40 visits × 200 = 8 千评估 ÷ ~1500/s（f32，3 GFLOP/叶子）≈ **5s/局** | 20 万 token × ~0.25ms ≈ **50s/局（10×）** |
| 训练 fwd+bwd / 局 | 200 局面样本 × (100 token × 90 MFLOP) ≈ **1.8 TFLOP** | 20 万 token 位 × 90 MFLOP ≈ **18 TFLOP（10×）** |
| 两周预算 | **3–5 万局** | **3–5 千局** |
| 冷启动 | 人类棋谱直接可用（策略模仿） | **链无处可 SFT**——SGF 无人写过思考链 |

"训练成本可能更低"的方向反了：**至少 10×**，且未计入从零学盘面推演的隐性成本。
截短思考链（100–300 token）可线性降本，但质量掉到 5–10 手线性读棋，仍无回传。

## 4. R1 三前置，全缺

| R1 能成的前提 | 本项目 |
|---|---|
| base model 已读过海量推理 trace（"aha 涌现"的土壤） | **无**——B 是 10M 参数 go 专用网络，无语言、无语料 |
| 有更强模型可蒸馏长链（R1 冷启动 = 蒸馏强模型） | **无**——唯一比我们强的可蒸馏对象是 MCTS（§5） |
| 短链 + 密集结果奖励 | **反**——一个胜负信号覆盖 200 手 × 1000 token ≈ **20 万 token 的信用分配**（MCTS 的价值回传本质就是这个信用分配器——扔掉搜索等于扔掉它） |

## 5. 关键路径论证（对赌约的裁决，不依赖谁强谁弱）

**thinking 的冷启动数据唯一来源是 MCTS 蒸馏**（§4 第二行）：把搜索树的主变化线
+ Q 值序列化成结构化 token 教网络复述。⇒ 即使 thinking 最终比 MCTS 强，
**它依赖 M8、排在关键路径最后**，赌约时间线内塞不下。这是依赖顺序问题，
不是偏好问题。

## 6. Go 自进化 RL 出思考链：形式上行，且比 LLM 更"可验证"

- **形式上成立**：胜负可验证 = 标准 RLVR 形态。
- **Go 独有优势**：结构化思考链的**每一步都能被规则引擎精确验证**——
  "黑 A 白 B 后黑提 3 子"对错一查便知。数学题只有最终答案可验证；LLM 拿不到
  中间步骤的 verifiable reward。**前提是链必须是结构化 token（坐标/局面声明），
  不是自然语言**——而没有语料的结构化链，冷启动只能来自 MCTS 蒸馏（回到 §5）。
- 结论：可行的版本 = §7 的 M10，不是从零自进化。

## 7. 对照表与建议

| 方案 | 单节点推理成本 | 节点质量 | 训练/局 | 冷启动 | 裁决 |
|---|---|---|---|---|---|
| 纯 thinking（隐状态推演） | ~5× 便宜 | 无精确盘面 / 无回传 | 10× | 无数据 | ❌ 不进主线 |
| thinking + 环境反馈（推一手→规则引擎重灌盘面） | 同上 | = **无树、无回传、无批量的退化搜索**，严格 ≤ MCTS | ≥10× | 无数据 | ❌ 不进主线 |
| **MCTS（主线 M8）** | 1×（批量最优） | 精确盘面 + 价值回传 + PUCT | 1× | 人类棋谱直接可用 | ✅ 主线 |
| **MCTS → 结构化链蒸馏 + 规则引擎逐步验证奖励** | 推理成本可变 | 训练期全有 | 主线 + 蒸馏 SFT/RL | **就是 MCTS** | 🔶 **M10 候选**（赌约后） |

**建议**：主线一动不动（roadmap M0–M9）。thinking 不是被否定，是被排到了它依赖
的位置之后。M10 若立项，"结构化坐标链 + 逐步可验证奖励"是本项目真正独有、
文献里少见的创新点——创新性高于"直出坐标"本身。与 M10 前的一切无关。

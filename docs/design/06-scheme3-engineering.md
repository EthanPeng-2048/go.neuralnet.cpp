## 3. 教师标注管线

- 教师 = KataGo（版本 + 网络权重固定并记录哈希）；学生训练数据 = 双预算树对
  （π^L = 100–400 visits，π^H = 预算见 §4）。
- **每局面必须落盘**（可重放记录）：规则/贴目/手数、颜色、合法掩码、教师版本
  与权重哈希、visits、根噪声开关与温度、`maxTime`、根先验、**完整节点表**
  (W/N/Q/prior/parent/action)。没有它就无法生成 Δz*（05 §5）与验证 token 合法性。
- **工程缺口【待核实】**：KataGo 的 analysis/selfplay 输出不含完整节点表导出，
  预计需给 KataGo 打补丁（其代码开源，可做，但是一项未列入任何里程碑的新工作）。
- 数据规模沿用 v0.2 上限目标（5–10 万 / 2–5 万 / 1–2 万），先做**成本闸门**：
  500 局面试点，实测"每秒标注局面数 × dump 体积"，反推全量墙钟。

## 4. 教师预算算术（**赌约核心，评估新增**）

等墙钟条款下的铁律：**学生 ≤ 教师**（蒸馏基本不等式），而对手在对局中实时
获得 N_opp(T) visits 的搜索。三段论：

1. 对手 4060 在 19×19、T 秒预算下 ≈ 数百–两千 visits/秒 × T【待实测】；
2. v0.2 起步配置 π^H = 800–1600 visits ≈ **对手等墙钟搜索量**，压缩（学生）
   还必有损 ⇒ **等墙钟条款下即使 H1 成立也追不平**；
3. v0.2 §3.5 的兜底"成本超限就把 π^H 降到 800"**方向与赌约目标相反**——
   教师预算必须**高于**对手对局 visits 若干倍，而不是更低。

两条修法（择一或组合）：

- **修法 ①（推荐）：赌约条款 = 固定 visits**，上限 ≤ 教师预算的 1/5
  （如教师 1600 → 条款 ≤300 visits）。此时教师远强于对手搜索量，压缩损耗
  有了余量。与 roadmap §2 的条款建议一致。
- **修法 ②：离线加大教师**：π^H = 8–16k visits，代价 ≈ 10× 标注墙钟
  （40HX 上按实测 visits/秒折算，预计数周量级）⇒ 必须缩局面集到
  **1–2 万关键局面**（对杀/劫争/胜负处优先），而非全量。

无论哪条，**教师预算与赌约 visits 上限必须在标注启动前一起定死**。

## 5. 里程碑（继承 v0.2 §8；M0 为硬闸门）

| 里程碑 | 交付物 | 成功判据 |
|---|---|---|
| **M0** | 序列化器 + 重放器 + 残差探针 | 重放 top-1 ≥70%；残差探针相对 π_low 提升 ≥8pp【验收参数】。**不过 = 全线停** |
| **M1** | Encoder + 双头基线（= roadmap M7 的等价物） | 同 visits 对 KataGo >30%（≥200 局） |
| **M2** | Top-K 结构 Decoder + 残差头 | 末端与 π^H top-1 ≥50%，优于等参数纯 BC |
| **M3** | 自回归完整运行 | 合法率 >99%；同延迟优于 M1；打乱消融显著掉点 |
| **M4** | 时间条件自适应停止 | 平均延迟 −20% 胜率不降；早停致错率有界 |
| **M5** | 完整系统 Pareto 对比 | 见 §6 统计修正 |

**日历缺口【必须补】**：v0.2 无任何时间估计。补法：M0 前置动作（§8 并行批）
做完后按实测标注速度反推；在赌约日期倒排前不得启动全量标注。

## 6. 评估协议（继承 + 统计功效修正）

- **主对比**：相同单步墙钟预算，固定对手网络/规则/种子池；执黑执白分开报告。
- **Pareto 前沿**（核心图表）：横轴单步延迟（10/50/100/300/1000ms），纵轴对
  固定基线胜率；曲线 = KataGo(不同 visits) / 本系统(不同 L₀、停止阈值) /
  关残差头 / 关自适应。**主张成立 = 本系统曲线在低成本区间 dominate**。
- **等效 visits 折算**：教师 visits→质量曲线反插值 N_eq(d)，报告 N_eq(d)/d；
  禁用无来源公式。
- **统计功效修正【评估新增】**：400 局下胜率 45% 的 95% CI ≈ ±4.9%——
  **分不开 45% 与 50%**。修正：方向性判断 ≥800 局；正式判定用 **SPRT**
  （Elo 界，如 ±50 Elo / 5% 误判），复用 roadmap M6 的 Arena。
- 停止头校准：可靠性图 + **早停致错率**（校准度>70% 不够，须报胜率损失）。
- 结构保真度：合法率 / 归一化编辑距离 / 访问分布 Jaccard / 打乱消融。
- 专项分桶：征子/对杀/劫争/循环/大模样。

## 7. 对局形态与部署

- 单步推理预算（神经网络侧）：Encoder 一次前向 + ≤48 步 Decoder 增量解码。
  【待实测】40HX f32 下估算 ~10–25ms/步（权重流量主导）；V100 若装机可压缩
  但非必需。
- **剩余时间的免费增强**：单步 20ms vs 条款 1000ms ⇒ 可做 N 次独立思考采样
  + 投票（v0.2 未提，成本近零，列为 M5 的可选曲线）。
- 对局接口：GTP（roadmap M6），对手可用 Sabaki/命令行 KataGo 对接。
